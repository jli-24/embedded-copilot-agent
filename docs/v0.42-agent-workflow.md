# Embedded Copilot v0.42 Agent Workflow Layer

Status: Released

v0.42 introduces a framework-independent, planning-only Workflow Runtime. It
projects caller-owned requirements through injected Requirement, Context and
Planning ports, validates a deterministic task DAG, requires whole-workflow
human approval and returns scheduling batches with synchronous progress events.

`WorkflowContextPort` is an external composition boundary. Knowledge, Memory
and future Project Context adapters may collaborate behind that port, while the
Workflow Runtime sees only a metadata-safe `WorkflowContextProjection`.

Risk projection is read-only. It is visible to planning, human approval and
progress/reporting, but cannot change task priority, scheduling order, DAG
dependencies or Agent selection.

This development version does not execute tasks and does not provide Agent,
LLM, Tool, build, firmware/PCB generation, file mutation, Flash, Debug or
hardware-control capabilities.
