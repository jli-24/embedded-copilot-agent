# v2.9 Multimodal Input Layer Boundary

v2.9 is an Engineering Projection Layer, not a Runtime Agent layer.

The fixed data flow is:

```text
Safe Input Reference
  -> VisionModelPort
  -> VisionObservation
  -> optional EngineeringReasoningPort
  -> EngineeringInterpretation
  -> read-only API/UI Projection
```

The v2.9 boundary does not add an Agent, Workflow node, Runtime component, model SDK,
network access, filesystem access, database, Build, Flash, or Device Control capability.

Only explicitly injected v2.9 Ports are available to the v2.9 API. Without those Ports,
the API returns `503 MULTIMODAL_UNAVAILABLE`. Existing Vision and Reasoning API behavior
remains separated from this boundary.

The fixed Runtime Agent set remains:

- Supervisor
- Knowledge
- Firmware
- Debug

The v2.9 UI consumes read-only Observation, Interpretation, confidence, and source
reference projections. It does not apply, modify, generate, execute, build, or flash
engineering assets.
