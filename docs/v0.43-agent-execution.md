# Embedded Copilot v0.43 Agent Execution Layer

Status: Released

## Scope

v0.43 adds a framework-independent execution boundary between an approved workflow
task and a caller-owned agent capability. The runtime performs exact capability
resolution, typed invocation, result projection, independent verification, bounded
human-approved recovery, and content-free progress reporting.

```text
Approved Workflow Task
  -> explicit execution projection
  -> exact Agent Registry resolution
  -> caller-owned AgentExecutionBoundaryPort
  -> safe result projection
  -> ExecutionVerificationPort
  -> immutable AgentExecutionSnapshot
```

## Safety boundary

- The runtime does not infer agent type from task text.
- It does not import Supervisor, LangGraph, Tool Runtime, Knowledge internals, or
  Engineering Memory storage.
- It does not execute shell commands, access files or networks, or mutate engineering
  state.
- Agent and verifier results cross the boundary through typed deep copies and contract
  revalidation, without a serialization round-trip.
- One failed initial attempt may enter human review and receive at most one approved
  recovery attempt.
- Progress events contain identifiers, state, sequence, and caller-provided time only.

## Non-goals

This release does not add autonomous agents, tool execution, workspace
writes, firmware or PCB generation, hardware control, retry loops, API endpoints, or
user-interface integration.
