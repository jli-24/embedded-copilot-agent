# Embedded Copilot v0.41.0 Knowledge Intelligence Layer

状态：release candidate

v0.41 新增 framework-independent、read-only 的 Knowledge Intelligence Layer。
固定控制方向为：

```text
Supervisor
  -> requests Knowledge
  -> receives Verified Evidence
  -> uses evidence during Planning
  -> remains responsible for tasks and routing
```

本层包含 typed Port、确定性 Verification、Graph Projection、不可变 Snapshot、
Knowledge Provenance 和只读 Engineering Memory candidate bridge。
`KnowledgeProvenance` 保存 source type、publisher、reference、verification
method、调用方提供的 verification time 和 verified confidence，使工程结论能够
追溯到原始依据。

Knowledge Graph 只是 Evidence Projection。它不生成任务、不选择 Agent、不创建
`SupervisorPlan`、不调用 Tool，也不触发执行。Memory Bridge 只投影 typed
candidate；它不调用 Engineering Memory Port，也不修改永久项目规则。

该开发版本不包含 Neo4j、browser/HTTP transport、自动 PDF 下载、自主搜索循环、
JSON persistence 或任何自动 Memory mutation。外部 Research 和 Datasheet 能力
只能通过既有或 transport-neutral Port 注入，并且每个请求最多调用一次。
