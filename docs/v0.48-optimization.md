# Embedded Copilot v0.48 Optimization Layer

Status: Released

## 范围

Optimization Runtime 是 framework-independent、deterministic、proposal-only
的安全边界。它将类型化硬件观测投影为受约束的优化候选，执行确定性评估，并在返回终态快照前要求显式人工决策。

```text
HardwareObservation
  -> OptimizationRequest
  -> exact algorithm binding
  -> unverified proposal
  -> deterministic evaluation
  -> human approval
  -> immutable snapshot
```

## 安全边界

- Runtime 不修改 firmware、文件、设备或工程状态。
- Runtime 不执行 Build、Flash、Debug、Shell、Git、USB、串口或网络操作。
- PID 只是无状态数学候选投影，不是真实控制器。
- 功耗与性能结果是固定的确定性模型投影，不代表硬件测量或已验证的优化结论。
- Approval 仅确认候选已经人工审查，不执行控制动作。
- Runtime-local replay isolation 仅在当前进程内有效，不提供跨进程 replay protection。

真实硬件控制、在线调参、持久化优化历史、模型训练和自主优化均为 v0.48 的明确非目标。
