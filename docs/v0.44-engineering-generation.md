# Embedded Copilot v0.44 Engineering Generation Layer

Status: Released

## Purpose

v0.44 introduces a framework-independent, approval-controlled foundation for
creating reviewable engineering artifact proposals. It extends the public
Workflow Task and Agent Execution result flow without modifying either runtime.

```text
Workflow Task
    ↓
Agent Execution Result
    ↓
Generation Request
    ↓
Explicit Generator Registry
    ↓
Typed Artifact Proposal
    ↓
Independent Verification Projection
    ↓
Human Approval
    ↓
Approved Artifact Reference
```

## Boundaries

- The registry uses exact generator capability binding and never falls back.
- Generator implementations and their lifecycles remain caller-owned.
- Context contains only safe summaries and typed reference identifiers.
- Proposals are immutable, fingerprinted structures for hardware design,
  firmware structure, PCB constraints, or BOM review.
- Verification is an injected projection boundary. It does not perform DRC,
  compilation, build, or hardware testing.
- Every proposal requires explicit human approval before an approved reference
  can be produced.
- Progress delivery is synchronous, content-free, and fail-closed.

## Non-goals

This release does not generate complete KiCad projects, perform PCB
layout, write project files, build firmware, flash devices, control hardware,
invoke tools, or create Git commits. Its outputs are proposals requiring
engineering review; they are not evidence of real generation, compilation, or
hardware validation.
