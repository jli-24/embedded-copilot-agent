# Engineering Memory Knowledge Model

此页描述 [[Engineering Memory]] 在知识系统中的作用：保存设计决策、问题、解决方案、失败尝试与优化结果，并通过候选/已验证隔离避免把推测传播为事实。v0.39 的实现不包含真实持久化、RAG 或 Agent 自动调用。
