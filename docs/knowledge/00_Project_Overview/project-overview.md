# Embedded Copilot Agent

Embedded Copilot Agent 是面向嵌入式研发的 AI 工程助手。当前仓库以 Runtime、Protocol、受控 Tool 与验证边界为基础；最终愿景是 RAG + Multi-Agent + Multimodal 的工程闭环。

## 当前事实

- 最新已发布版本：v0.39 Engineering Memory Layer。
- 当前实现强调确定性、冻结 DTO、审计、最小权限和 Workspace 写入边界。
- [[docs/knowledge/02_Agent_Design/hardware-agent|Hardware Agent]]、[[docs/knowledge/02_Agent_Design/pcb-agent|PCB Agent]]、自动执行、HIL 与优化闭环均不得因本知识库而被视作当前可用。
