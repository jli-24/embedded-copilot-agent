# Verification Agent

[[Verification Agent]] 在 v0.38 发布，提供确定性候选验证基础。`PASS`、`FAIL`、`REVIEW_REQUIRED` 表示规则验证结果，不等同于真实硬件已验证；候选是否启用仍需要工程师确认。
