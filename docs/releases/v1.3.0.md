# Embedded Copilot v1.3.0 Release

## Overview

v1.3.0 adds the Engineering Execution Layer: typed Firmware Agent proposals,
approved ESP-IDF build delegation, and deterministic Engineering Observation
projections for the Web Console.

## Implemented Contracts

- FirmwareAgentPort produces bounded firmware proposals.
- ESPIdfBuildExecutionPort receives approval-bound build invocations.
- BuildResult is projected into the Engineering Observation Layer.
- The Web Console presents artifact, build, and observation projections.

## Security Boundary

The layer does not execute shell commands, does not write files, and does not control hardware.
It owns no subprocess, filesystem, database, network, device,
or credential adapter. Real build and device integrations remain caller-owned
Ports and require explicit approval.

## Validation Scope

Focused Firmware Agent, Execution, Engineering Observation, Web API, frontend
contract, and security-boundary tests validate deterministic contracts and
optional dependency injection. This release does not claim a real ESP-IDF build
or physical-device verification.
