# Embedded Copilot Agent v0.20.0

## Version History

v0.20.0 在 v0.19.0 product demo 基础上增加 Evaluation & Release Engineering。版本未新增
Agent、Parser、Provider 或 Workflow node，也未改变 Agent API、`EngineeringReport` 或
FastAPI contract。

## Architecture

新增 `embedded_copilot.evaluation` 作为同步、离线的外部观察层。它复用现有 3-case
synthetic integration dataset，通过现有 Supervisor adapter 注入 metadata-only context，
调用显式注入的 Supervisor，并将返回的 `EngineeringReport` 转换为 frozen、
`extra="forbid"` 的 `EvaluationReport`。

Streamlit 增加 Overview、Workbench、Benchmark 和 Example Report 四个视图。Workbench
继续只通过 FastAPI client 发起分析；其他视图只消费安全 projection，不执行 Runtime Agent。

## Benchmark Results

deterministic release snapshot 包含 3 个 synthetic end-to-end cases：3 passed、0 failed。
Task Routing Accuracy、Agent Success Rate、Report Completeness 和 Evidence Traceability 均为
`1.0`。Dashboard 使用 injected fixed clock 的 1/2/3 ms 样本，average latency 为 2 ms、
maximum latency 为 3 ms；这些数值只验证计时与渲染 contract，不代表生产性能。

真实 total latency 会随本机负载变化。当前公共边界没有可靠的 per-Agent timing，报告明确
使用 `agent_latency_status="unavailable"`，不估算或补造数据。

## Known Limitations

- 不自动修改 PCB，不自动烧录设备。
- 不替代 EDA DRC、ERC、connectivity verification 或人工审核。
- 不使用 LLM fallback 提高 Parser 覆盖率。
- Evaluation 不衡量硬件实时性能，逐 Agent latency 不可用。
- CI workflow 是仓库配置；只有 GitHub Actions 实际执行后才能声明 hosted CI 通过。
- Docker CLI 不存在时只进行 Dockerfile/compose 静态验证，不能声明容器运行通过。

## Future Roadmap

后续版本可在不破坏现有 contract 的前提下扩展更多受控 synthetic scenarios、release
baseline comparison 和经独立设计批准的可观测性。任何 per-Agent timing、在线 judge、
外部服务或持久化能力都必须先批准新的 scope、privacy boundary 和迁移方案。
