# Embedded Copilot v0.36.0

## Scope

v0.36.0 新增 framework-independent、deterministic、observation-only 的
Telemetry Intelligence Layer。它接收 caller-owned `TelemetrySourcePort`，通过
`TelemetryPort` 返回带指纹的单点样本、一次请求内的有界序列，以及仅基于数值输入的确定性
统计、endpoint direction 趋势和待人工复核的异常候选。

## Architecture Boundary

- `create_telemetry_runtime()` 只接收非空 source tuple 与 audit sink。
- `DEBUG_RUNTIME` 和 `MOCK` 都是 caller-owned source；Runtime 不持有 `DebugPort`。
- 精确按 source type 路由，缺失或失败时不 fallback。
- `collect_series()` 使用 bounded synchronous pull；不 sleep、不轮询、不跨请求积累。
- `DebugTelemetryContext.to_sample()` 仅投影 Debug Snapshot 中的 telemetry metrics。
- 所有有效公开操作最多产生一个使用 caller-provided UTC timestamp 的无内容 audit event。

## Deterministic Analysis

统计仅包含 minimum、maximum、`math.fsum` average、端点 delta 和 sample count。
Trend 仅表示 endpoint direction，不声明中间样本单调，也不推断 root cause。异常阈值完全由
caller 在分析请求中提供；越界结果始终使用 `candidate_semantics="unverified"` 并要求
engineer review。

## Security

样本与序列均使用 canonical JSON 和 SHA-256 指纹，并在构造时复核。Runtime 对 source
输出进行深拷贝、重新验证和 target/source binding 检查。它不缓存或持久化 sample、
series、analysis 或 audit state，也不读取系统时钟、生成随机标识或启动后台任务。

## Limitations

本版不提供 PID optimization、automatic tuning、hardware control、Flash、reset、
真实设备写入、Agent、LLM、RAG、API、UI、network、database、filesystem、Shell、
subprocess、Git、后台采集或持久化。

本版没有 real transport 或真实 source SDK，也不构成 real-time system 或 hardware validation。
离线测试通过只验证 contract 与 deterministic behavior，不代表真实设备、
采样时序或硬件性能已验证。
