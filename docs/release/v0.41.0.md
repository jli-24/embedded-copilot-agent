# Embedded Copilot v0.41.0

## Release Overview

v0.41.0 新增 framework-independent、read-only 的 Knowledge Intelligence Layer。固定控制方向为：

```text
Supervisor
  -> 请求 Knowledge
  -> 获得 Verified Evidence
  -> 使用 Evidence 辅助 Planning
  -> Supervisor 决定任务与路由
```

Knowledge Graph 不是决策中心，不生成任务、不选择 Agent、不构造 `SupervisorPlan`，也不触发执行。

## Knowledge Intelligence Layer

- `KnowledgeIntelligenceRuntime` facade 只公开 `knowledge_port()`。
- Web Research 通过 caller-owned `WebResearchSourcePort` 注入，每个请求只进行一次有界调用。
- Datasheet 使用调用方显式提供的 typed request，并复用既有 `DatasheetIntelligencePort`。
- 所有 DTO frozen、strict、`extra="forbid"`、tuple-only，并使用确定性序列化。
- Runtime 不读取系统时钟、不生成 ID、不缓存或持久化输入和结果。

## Verification Model

构造期注入的 immutable `SourceTrustCatalog` 提供确定性验证规则：

- 无冲突的权威来源允许单源 VERIFIED。
- Community/Web 需要两个独立 publisher 提供相同 canonical fact。
- 同一 publisher 的重复结果不构成独立来源。
- 矛盾事实为 REVIEW_REQUIRED，未知来源为 REJECTED。
- Provider 自报 confidence 不作为可信依据。

只有 VERIFIED evidence 可以进入 Graph、Planning 或 Memory Bridge。每条 verified evidence 携带
`KnowledgeProvenance`，包含 source type、publisher、reference、verification method、调用方提供的
UTC `verified_at` 和固定 `confidence=1.0`，支持回答工程结论的来源与验证依据。

## Knowledge Graph

Verified Evidence 被纯函数投影为 entity、relation 和 `FrozenKnowledgeGraphSnapshot`。Snapshot
使用固定排序、canonical JSON 和 SHA-256 fingerprint，并在构造时复核。Graph query 只输出
Evidence Projection；首版 conflict detection 只返回显式 `conflicts` relationship，不推断 GPIO、
电气或时序冲突。

## Memory Learning Bridge

Memory Bridge 只接受 VERIFIED Failure Rule，输出可审查的 `KnownIssueMemory` CANDIDATE 与既有
`CreateCandidateRequest` binding。Bridge 不调用 `EngineeringMemoryPort.execute()`，不生成
`ApplyVerificationRequest`，不创建 VERIFIED record，也不自动修改永久规则。实际写入继续由既有
Permission、Audit、Verification/Human Approval lifecycle 控制。

## Supervisor Integration

Supervisor 通过可选 `KnowledgeIntelligencePort` 获得 verified-only Planning projection。未配置时
保持 v0.40 Knowledge Gateway 行为；Knowledge failure 时安全降级到 memory-only 或 empty context。
Agent handoff 不包含 graph snapshot、raw evidence、source content、verification body 或 Memory proposal。
安全 `knowledge_trace` 只含 sequence、stage、status、count 和 source type。

## Security Boundary

- 不包含 Neo4j、database、JSON persistence 或 mutable global graph。
- 不包含 browser、HTTP client、crawler、自动 PDF 下载或 network transport。
- 不包含自主搜索循环、retry loop、后台任务、Agent/LLM 控制或自动 Memory mutation。
- Knowledge package 不导入 Supervisor planner、dispatcher、Agent implementation 或 Tool execution。
- Workspace Runtime 继续保持唯一文件写边界。

## Non Goals

本版本不实现生产 Web crawler、自动浏览器、自动下载 Datasheet、Neo4j、Knowledge-driven routing、
自主 Agent search loop、永久 Memory rule mutation、HTTP API 扩展或真实在线来源验证。
