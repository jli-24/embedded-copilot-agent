# Embedded Copilot v0.23.0-alpha1

本版本在不改变既有 Supervisor、LangGraph、Hardware Design Artifact、Engineering Report 和公共 API 合同的前提下，提供 Adapter-first Intelligence Platform Foundation。该版本用于本地 alpha 验证，不是 production-ready release。

## Added

- Model Gateway：只产生 suggestion-only reasoning output，并通过 provider isolation 保持模型实现与工程状态隔离。
- Knowledge Intelligence：新增 `KnowledgeEvidence` 和 `KnowledgeTrace`，保留候选知识与检索来源之间的可追踪绑定。
- Search Intelligence：新增 approval staging；只有用户批准的安全摘要和来源 metadata 才能进入 Knowledge ingestion。
- Conversation Backend：使用 process-local repository，并通过 reasoning expiration 保证完整模型响应、reasoning chain 和临时上下文不会进入会话存储。
- Copilot API：新增 `/api/v1/copilot/sessions` 和 `/api/v1/copilot/sessions/{session_id}/messages` 等 additive sessions/messages endpoints。
- ESP32 preparation：新增 metadata-only ESP32 handoff，只传递显式 Workspace metadata、候选知识和 reasoning suggestion。

## Architecture Boundary

- Intelligence Layer 不拥有 Engineering Artifact lifecycle，不创建 Engineering Fact，也不修改 Decision、Evidence、Approval。
- Model Gateway output 只是 reasoning suggestion，不能直接修改 Artifact 或升级为工程事实。
- Knowledge/Search content 只是候选信息；Knowledge ingestion 不会自动将其升级为可信 Engineering Evidence。
- Engineering Agent Layer 必须独立验证候选信息，并独立创建 Artifact facts；Intelligence Layer 不持久化验证结果或工程决策。
