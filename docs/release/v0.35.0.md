# Embedded Copilot v0.35.0

## Scope

v0.35.0 adds a framework-independent, observation-only Embedded Debug Runtime.
It accepts caller-owned `DebugSourcePort` implementations for UART, J-Link,
ST-Link, and GDB, then exposes normalized target identity, bounded debug
snapshots, telemetry, and content-free audit events through one `DebugPort`.

## Architecture Boundary

- `create_debug_runtime()` receives a non-empty immutable source tuple and an
  audit sink.
- Routing is deterministic by source type and never falls back.
- The Runtime neither constructs nor owns a connection, process, device handle,
  transport, credential, or provider lifecycle.
- Every successful or failed valid request emits a synchronous audit event using
  the caller-provided UTC timestamp.
- Workspace Runtime remains the only file write boundary.

## Security

Observations are normalized and bounded. Public snapshots exclude source code,
paths, locals, arguments, memory dumps, firmware images, credentials, device
secrets, provider errors, and tracebacks. The Runtime does not cache or persist
identity, logs, register data, stack frames, telemetry, or audit state.

## Limitations

This release does not implement a hardware transport, install a device SDK, or
connect to physical hardware. It does not implement Agent orchestration, model
or Reasoning Runtime invocation, automatic debugging, API, UI, networking,
filesystem access, Shell, subprocess, Git, build, flash, reset, erase, program,
register or memory write, continue, step, or breakpoint control.

The adapters are contracts for injected observation sources. Passing the
offline test suite does not constitute real-device, transport, timing, or
hardware validation.
