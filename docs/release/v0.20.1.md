# Embedded Copilot Agent v0.20.1 Product Readiness

## 发布范围

v0.20.1 是兼容性的 Product Readiness patch，范围仅包括 Web 产品化收尾、Product API
Client 稳定性、Demo metadata 校正、测试与发布文档。它不新增 Agent、Parser、Provider 或
Workflow node，也不修改 FastAPI contract、Agent API、`EngineeringReport` schema、Docker
runtime contract 或依赖声明。

## Web 产品化收尾

- 四个视图中文化为“概览”“工程工作台”“评测基准”“示例报告”。
- 保留 Embedded Copilot、LangGraph、RAG、FastAPI、EngineeringReport 与既有 Agent 名称。
- 保留 `Load Demo`、`Analyze`、`Queued`、`Running`、`Completed` 产品流程关键词。
- 示例 `EngineeringReport` 的说明、证据与建议改为中文，技术字段和值保持兼容。
- FAILED 状态不显示服务端未知错误正文，也不继续展示旧报告。

## Product API Client 稳定性

ProductApiClient 对以下失败使用固定中文提示：

- connection error
- timeout
- HTTP error
- invalid JSON
- schema validation failure

错误不会包含 request、URL path、token、底层异常原文或未知服务端 `detail`。三个 public
client 方法与 payload/response contract 保持不变。

## Demo Metadata

ESP32 Camera manifest 的名称与工程需求已中文化。四个 `size_bytes` 由附件文件的
`Path.stat().st_size` 校正，测试禁止读取附件正文，并验证 manifest metadata 与文件系统
metadata 一致。

## 验证

候选版本执行以下离线质量门：

```powershell
pytest -q
ruff check .
python -m compileall -q src tests
git diff --check
```

Web focused tests覆盖安全错误映射、中文导航、report cache、FAILED 状态、Demo metadata 与
示例报告。全量验证结果以本次收尾任务的最终执行输出为准。

## 兼容性与安全边界

- 不修改 `src/embedded_copilot/**`。
- 不修改 `requirements.txt` 或 `pyproject.toml`。
- 不修改 FastAPI path、method、request/response contract。
- 不修改 `EngineeringReport` schema 或持久化结构。
- Web 继续只通过 ProductApiClient 使用 Product API。
- metadata-only 附件边界与 Docker runtime contract 保持不变。

## 已知限制

- 当前 package、runtime health metadata 与既有 release baseline 仍为 `0.20.0`。
- 在版本 metadata 获得独立变更批准并同步前，不应创建 v0.20.1 tag。
- Benchmark fixed-clock latency 只验证 contract，不代表生产性能。
- 不自动修改 PCB、不自动烧录设备，不替代 EDA DRC、人工审核或真实硬件验证。
