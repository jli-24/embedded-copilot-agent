# Embedded Copilot v0.40.0

## Summary

v0.40.0 新增 read-side Memory Intelligence Layer。它在不修改 v0.39 Engineering
Memory persistence、permission、audit、verification、snapshot 或 record contract 的前提下，
把经过验证的工程记忆投影为确定性的规划上下文，并与 Knowledge Gateway 的结果融合。

## Memory Intelligence Layer

- `VerifiedMemoryReadProjection` 只接受满足 verification 和 revision/history 一致性的记录。
- `MemoryRetrievalRequest`、`MemoryContext` 和 evidence contracts 均保持 frozen、strict 和
  deterministic。
- Domain mapping 仅依据 record type、verification subject 和 provenance，不使用自由文本猜测。
- Ranking 使用固定 trust、domain、usage、recency 因子及稳定 tie-break，不调用 LLM。
- Ranked Context Builder 生成稳定 context fingerprint，不返回部分或未验证结果。

## Knowledge Fusion

Knowledge Gateway 将 Knowledge 与 Memory 作为两个独立可选来源。`EngineeringPlanningContext`
只保存安全投影、来源引用、ranking/trust basis 和稳定 fingerprint；confidence 由非空输入的
最低可信度确定。任一来源不可用时，Supervisor 只使用仍然有效的来源。

## Failure-safe Supervisor

Memory retrieval、Knowledge retrieval、context fusion 或 context-aware planning 失败时，
Supervisor 使用脱敏 trace 并安全降级到可用上下文或 legacy planner。失败不会触发 retry、
恢复状态机或权限旁路，也不会把半构造 context 传递给 Agent。

Typed Supervisor input envelope 在安全投影中保持运行时类型，通过 deep copy 隔离调用方对象，
不经过 serialization round-trip。合法 typed context 只用于分析与规划，不进入 Agent handoff
或最终结果。

## Engineering Runtime

Engineering Runtime extension 支持 Firmware 与 Hardware 输入的既有离线分析和
`EngineeringReport` 聚合。v0.40 仅修复回归兼容性，不改变 AgentResult、Supervisor dispatch
或 report contract。

## Security Boundary

- Supervisor 只能通过 `EngineeringMemoryRetriever` 访问 Engineering Memory public port。
- Permission denial 和 audit failure 均以不透明、无数据泄漏的 fallback 处理。
- Planning context、Agent handoff、trace 和 legacy Agent Result 不暴露 payload、Finding、
  Approval、raw verification、record、provider、path 或底层异常。
- Legacy Agent Result metadata 使用 allowlist 安全投影；typed input context 保持隔离与不可变。
